## 2026-10-20: native cache lifetime across portals

- Diagnosis: scene loading calls Unity Resources.UnloadUnusedAssets; CLR dictionaries do not count as native references. Cached source animation Mesh frames and Texture2D wrappers could remain in .NET while their underlying Unity resources had been freed. A later cast reused the invalid wrappers. Existing EnemyVisuals Mesh.get_bounds failures demonstrate the same cache lifetime failure in the current player session; the VFX path had the same unprotected caching pattern.
- Cached source geometry frames and original texture uploads now use HideFlags.DontUnloadUnusedAsset. Per-instance particle/ribbon mesh and materials use the same native lifetime protection and are explicitly destroyed with their owning effect.
- Texture lookup validates Unity native liveness and re-uploads original RGBA bytes when necessary. Geometry lookup validates baked frames and rebuilds from the preserved source frame buffer if a resource was explicitly destroyed. Geometry tick checks only its selected frame, avoiding a full frame-cache scan every render tick.
- Stage Clear destroys scene effect instances only, retains the protected source caches, and resets transient failure suppression so a transition cannot permanently blacklist an effect. Dead scene instances are removed before the 64-effect admission limit is checked.
- Added public SpellVfxDiagnostics.SnapshotJson: cached/pinned/invalid mesh, texture and material counts, active/spawned effect counts and recovery counters. PrimeAllAssetsForProbe and PlayForProbe are restricted to batch mode with AZEROTH_LAB_HEADLESS_TEST=1; the portal smoke can warm all source assets, force UnloadUnusedAssets, then verify original effects on subsequent native stages.
- Build: AzerothAbilities Release, 0 warnings and 0 errors. Native portal smoke and deployment are coordinated by the root task; no native game launch, deployment, Git operation or map-marker layer change was performed by this subtask.
- Follow-up audit: Offers.cs used the same CLR-only Texture2D cache for native level-up cards. Prepared source spell icons now have DontUnloadUnusedAsset and native-null entries are evicted before a fresh RGBA upload. Offer generation, rarity logic, spell choices and source catalog are unchanged. Rebuilt AzerothAbilities Release with 0 errors and 0 warnings; SpellVfx.cs remains frozen.

- Final source verification corrected a missed earlier fast-path replacement: GeometryLayer.Tick now checks only its frame array shape and selected Mesh native liveness; it invokes full EnsureGeometry only when that array or frame is invalid.

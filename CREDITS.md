# MegaAzeroth — credits

This is a personal backup of the user's prepared MegaAzeroth installation for storage in the private `Solece/MegaAzeroth` repository. It combines the user's installed Megabonk with the MegaAzeroth modification and prepared resources converted from the user's installed Azeroth Survivors. The archive is not presented as a public redistribution of either game.

## Games and source resources

- **Megabonk:** the original game and its creators provide the engine integration, movement, physics, camera, enemy spawning and native game systems. Original game copyright, notices and license terms remain applicable.
- **Azeroth Survivors:** the original game and its creators provide the source class/spell/talent data, interface material and the source-game implementation studied for this adaptation.
- **World of Warcraft / Blizzard Entertainment:** original Warcraft models, textures, animations, interface artwork, names and other source resources retain their original authorship and rights. Conversion to meshes, JSON, PNG or raw RGBA does not turn them into newly authored MegaAzeroth artwork.

No ownership of the original games or their artwork is claimed. Existing notices supplied with the installed games are retained with those files. This credits file does not assign a new license to their contents.

## MegaAzeroth modification

Project: [Solece/MegaAzeroth](https://github.com/Solece/MegaAzeroth).

The project adds the class combat adapter, nine-hero selection, four open native tome slots, source-data conversion tools, hero/enemy visuals, spell VFX adapter, interface adapter, talent runtime, Elwynn environment adapter and test automation. Ten project plugin DLLs were inventoried in the accepted v5 runtime: AdventureFlow, AzerothAbilities, AzerothHud, BookSlots, EnemyVisuals, ElwynnBiome, HeroRoster, MageTalents, MageVisuals and TestBattle.

Development and testing were assisted by OpenAI Codex. Universal Modder supplied modding/reconnaissance and native window-recording tools; FFmpeg was used for reference video processing. Original-game reference captures were recorded from the original application. These development tools are not described as runtime requirements or as bundled components unless separately listed in the archive manifest. Original game artwork was converted from installed assets, not generated by an image model.

The project source code retains any license already present in the source repository. This file does not select a new source-code license.

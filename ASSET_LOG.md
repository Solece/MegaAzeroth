## 2026-10-20: portal asset lifetime and grounded Tarantula visuals

- EnemyVisuals had the same native-unload failure as MageVisuals: a managed Models dictionary kept wrappers but not native roots, then GetModel returned the stale Model without checking Template.bounds. Every owned template, baked animation frame, texture and material is now marked DontUnloadUnusedAsset. Cached models validate all frames/native vertex counts before reuse and reload if invalid. Load failures retry instead of permanently poisoning FailedModels; active visual instances retry/rebind after transient scene failures, restoring native appearance during the retry.
- Public EnemyVisualBridge.PrimeAllModelsForProbe() is restricted to batch mode plus AZEROTH_LAB_HEADLESS_TEST=1. It preloads and validates all eleven private packs. AssetDiagnostics() is read-only, performs live validation of every cached mesh/material/texture and reports allValid/sourceCount/expectedSourceCount/allElevenPrimed/modelLoads/recoveries/per-model native alive/retained mesh counts and Problems. The diagnostic itself never reloads resources, so forced native UnloadUnusedAssets tests retention directly.

Template-only positioning can therefore place animated geometry below its anchor, especially at boss scale. The previous boss anchor additionally used the native renderer minimum, which need not equal the physical floor.

Physics roots, colliders, AI and movement are never moved by this code.

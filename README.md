# MegaAzeroth

Личная экспериментальная сборка Megabonk с девятью классами, моделями, заклинаниями, талантами и интерфейсом Azeroth Survivors. Движение, физика, спавн противников и переходы между этапами остаются от Megabonk. Окружение Элвинна используется в процедурных обычных этапах Desert.

## Скачать и запустить

1. Войдите в GitHub под аккаунтом с доступом к этому приватному репозиторию и откройте [Releases](https://github.com/Solece/MegaAzeroth/releases).
2. Скачайте **MegaAzeroth-v0.5.1-private-windows-x64.zip** из Assets. Это полная сборка; архивы Source code содержат только исходники.
3. Распакуйте архив целиком в отдельную папку с правом записи, например `Games/MegaAzeroth`.
4. Запустите единственный **Play-MegaAzeroth.cmd**. Нажмите Enter для тестового режима или введите `2` для обычной прогрессии.

В архив входят Megabonk **1.0.69**, проверенные моды v5, подготовленные ассеты, BepInEx **6.0.0-be.755** / Doorstop **4.5.0**, встроенный .NET Runtime **6.0.7** и соответствующие этой версии interop-сборки. Отдельно скачивать Megabonk, устанавливать Azeroth Survivors, Python, Unity, Visual Studio или .NET SDK не требуется. Интернет для установки зависимостей сборке не нужен; подключение и авторизация Steam определяются самой игрой.

Нужны Windows 10/11 x64, подходящий для Megabonk компьютер и установленный Steam с аккаунтом, которому доступна игра. Проверка Steam не изменена. Распакованные файлы занимают около 0,91 ГБ; предусмотрите хотя бы 2 ГБ свободного места для архива и распаковки. Начальный запуск проверяет контрольные суммы всех файлов Runtime из манифеста.

## Режимы

- **Test — по умолчанию:** родное меню выбора всех девяти классов, 999 очков, максимальные таланты до боя, плотность декораций 1,2. Записи нативного прогресса и конфигурации в этой тестовой сессии подавлены. Сам бой начинается после выбора героя и карты.
- **Normal:** обычная прогрессия талантов и плотность декораций 1. Используется нативный профиль Megabonk и его сохранения; отдельный профиль игры для этого режима не заявляется.

**F6** открывает три дерева талантов выбранного класса. В сборку не включены личные сохранения, Steam-профиль, учётные данные и журналы предыдущих запусков. Запуск не зависит от локальных путей разработчика. Исходные установленные игры не меняются.

## Проверка, журналы и удаление

- При сбое проверьте `reports/` рядом с запускалкой и `Runtime/BepInEx/LogOutput.log`.
- Проверить архив без запуска игры можно командой `Play-MegaAzeroth.cmd -Verify` из его папки. После ручного изменения файлов сравнивайте с исходным архивом: полная проверка ожидает поставленные версии, включая первоначальные конфиги.
- Для удаления закройте эту сборку и удалите её распакованную папку. Нативные сохранения Megabonk находятся отдельно и этим не удаляются.
- Не обновляйте вложенные игровые файлы или загрузчик по отдельности: мод проверен с конкретными версиями и контрольными суммами. Чистые копии и прежние сборки можно хранить рядом.

## Меню и загрузка

Версия 0.5.1 использует оригинальный фон Azeroth с подтверждённым оттенком и размером 106%, исходные рамку и заполнение полосы загрузки. Полоса следует настоящему прогрессу Megabonk. В меню отключено размытие глубины и скрыты фоновые декорации, энты и ветер Megabonk; выбранный герой и нативные кнопки сохранены. При входе в игру исходные настройки рендера восстанавливаются. Геометрия затемнения и расположение полосы адаптированы к интерфейсу Megabonk.

## Содержимое и ограничения

Перенесены девять классов, каталоги 102 классовых заклинаний, 354 талантов и 27 деревьев. Сохранены четыре открытых слота книг Megabonk, нативные таймер и золото. Новые модели шести обычных противников и двух боссов дополняют прежний набор; обычные противники сохраняют уменьшенный размер, боссы — масштаб нативных моделей.

Это экспериментальная адаптация между разными движками. Полное визуальное совпадение всех графических проходов, естественное срабатывание каждого таланта, поведение всех питомцев и длительный баланс не подтверждены. Проверки v5 и их конкретные границы описаны в [MODLOG.md](MODLOG.md), [docs/ALL_HEROES.md](docs/ALL_HEROES.md), [docs/PALADIN_VFX_AUDIT.md](docs/PALADIN_VFX_AUDIT.md) и [docs/ENEMY_VARIETY_EXPANSION.md](docs/ENEMY_VARIETY_EXPANSION.md).
